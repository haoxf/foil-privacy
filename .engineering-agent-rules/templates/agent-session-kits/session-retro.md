# Session Retro（可选）

仅在下列情况使用：**用户要求**复盘/提炼；**卡住刹车**上报；或本轮确有明显拉扯/范围漂移/高成本等待。  
普通 handoff 或里程碑本身不是充分触发条件。  
**非强制。** 不要定时扫会话；成本只写定性大头，不编造精确耗时/token；说不清写「不明」。

安装路径：`.engineering-agent-rules/templates/agent-session-kits/session-retro.md`。项目私有注记可另写 overlay，不要改本托管文件。

## 短表

| 项 | 内容 |
| --- | --- |
| 卡住 / 反复点 | 失败签名或假设；已尝试路径/命令指针 |
| 转向动作 | 缩小复现 / 根因复核 / 外查；或说明跳过原因 |
| 规则缺口候选 | 是否像提示词/路由问题；仅当**本会话或已有证据**能确认是第二次同类浪费时，才提议改共享规则 |
| 主要成本（定性） | 时间：…；Token：…；拉扯：…；其他：… |
| 下一刀可砍 | 一句话 |

## 产物

- 默认当面短答用户；若正在写 handoff，可临时追加一段，不要把复盘空槽写进默认 handoff 骨架。
- 旁路非阻塞项：有项目账本才记（如 `Docs/deferred/`）；不要为复盘新建平台。
