# Foil Flashcards Privacy Policy

Public privacy policy for Foil Flashcards, hosted with GitHub Pages.

Published URL: <https://haoxf.github.io/foil-privacy/>

## Publish an update

1. Edit `index.html`.
2. Run `./publish.sh`.

The script verifies the expected GitHub repository, stages only the privacy-policy files, creates a commit when needed, and pushes the `main` branch.
